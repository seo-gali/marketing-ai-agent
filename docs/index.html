2. 무엇을 고쳤나요?

  • 너무 많은 요청 — 횟수와 입력 크기를 제한합니다.
  • 다른 사이트의 화면 조작 — 앱을 프레임에 넣지 못하게 합니다.
  • 숨겨진 링크 — 단축 주소·보이지 않는 문자를 검사합니다.
  • 누적 데이터와 화면 오류 — 이력을 나누고 복구 안내를 제공합니다.

3. 공격은 어떻게 이어지나요?

반복 조회 → API 쿼터 고갈 → 요청 제한으로 중단
다른 페이지에 화면 숨기기 → 실수 클릭 → 프레임 차단으로 중단
악성 댓글의 지시 → AI의 잘못된 초안 → 원문과 사람이 다시 확인

사람의 검토와 공개 배포 시 별도 인증은 여전히 필요합니다.
