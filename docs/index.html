Marketing AI Agent

세 단계로 진행하는 작업

  1. 01 · 조회 영상 선택

    지정 5개 채널의 최신 영상과 공개 자료 확인

  2. 02 · 검토 근거와 초안 확인

    Ollama 분석, 출처 확인, 광고 댓글 편집

  3. 03 · 승인 Chrome에서 게시

    본문 승인 후 글자별 입력 → 게시 → 확인

본인 테스트 영상에서 글자별 입력·게시·댓글 확인 완료. 근거와 댓글을 검토한 뒤 승인한 본문만 게시하는 방식입니다.
